# Raw Data

This directory MIGHT OR MIGHT NOT contain the original, unprocessed time-series data used in this project.

## Description
The raw dataset consists of timestamped numerical observations used for anomaly detection experiments.  
No preprocessing, normalization, feature engineering, or filtering has been applied to the data in this folder.

## Usage
Files in this directory should be treated as **read-only**.
All data cleaning, transformation, and feature engineering steps are performed in the notebooks and scripts located outside this directory.

## Notes
- Raw data files may be ignored in version control depending on file size and repository constraints.
- If raw data files are not present in this repository, they can be regenerated or obtained by following the data preparation steps described in the main project's README.

## Related Directories
- `notebooks/`: contains data loading and preprocessing workflows.
